# User Guide — Flappy Bird

## Objective
Guide the bird through gaps between oncoming pipes without hitting a pipe or the ground.

## Controls
- **Space**, **Arrow Up**, or **Click / Tap** anywhere on the game stage to flap upward.
- **Enter / Space / Tap** restarts after the brief `400 ms` Game Over cooldown.

## Modes, Hints & Medals
- **? Help:** Opens the in-game rules and medal reference (pauses active simulation).
- **Tutorial:** Launches Practice Mode with wider `190 px` pipes and slower scrolling—clear 2 pipes to complete.
- **💡 Hint:** Toggles a dashed target flight corridor inside the next approaching pipe gap.
- **Medals:** Bronze (`10+`), Silver (`20+`), Gold (`30+`), Platinum (`40+`).
- **Persistence:** Best score and mute preference save automatically to `localStorage`.
