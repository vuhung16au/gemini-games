# Quickstart — Flappy Bird

## Prerequisites
- **Node.js** 18+ and **npm**

## Local Setup & Play

From the repository root (unified web app):

```bash
npm run dev
```

Or standalone inside `games/flappy-bird/`:

```bash
cd games/flappy-bird
npm install
npm run dev
```

## Automated Tests & Build

```bash
npm test
npm run test:e2e
npx tsc --noEmit
npm run build
```
