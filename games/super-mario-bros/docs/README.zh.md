# 超级马力欧兄弟 (1985) — NES

任天堂 1985 年经典横版卷轴平台跳跃游戏 **超级马力欧兄弟 (Super Mario Bros.)** 的浏览器重现版，支持单人游玩 **第 1 世界（`1-1`、`1-2`、`1-3`、`1-4`）**。

## 核心特性
- **完整第 1 世界（`1-1` 至 `1-4`）：**
  - **1-1 地上关卡：** 经典 `?` 砖块、超级蘑菇、隐藏 1-UP、食人花水管、栗宝宝、慢慢龟、阶梯与终点旗杆。
  - **1-2 地下关卡：** 洞穴顶棚、垂直升降平台、金币队列与旗杆出口。
  - **1-3 树梢高空：** 高架木桥、水平/垂直移动平台与慢慢龟巡逻。
  - **1-4 库巴城堡：** 岩浆池、旋转火棒、喷火库巴以及通往奇诺比奥城堡信息的吊桥与斧头。
- **经典物理与道具：** 惯性跑动/行走、可变跳跃高度、超级蘑菇、火之花（弹跳火球）、无敌星与集满 100 金币奖励 1-UP。
