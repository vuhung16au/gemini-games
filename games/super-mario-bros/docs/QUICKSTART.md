# Super Mario Bros. (1985) — Quickstart

Run all commands from `games/super-mario-bros/`:

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run Vitest unit tests
npm test

# Run Playwright E2E browser tests (port 4183)
npm run test:e2e

# Type-check and produce static production build (dist/)
npx tsc --noEmit && npm run build

# Preview production build locally
npm run preview
```
