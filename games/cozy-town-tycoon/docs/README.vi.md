# Ông Trùm Thị Trấn Ấm Áp — Tiệm Bánh Pixel

Tựa game mô phỏng/nhàn rỗi tiệm bánh pixel 16-bit ấm áp xây dựng bằng **React 18 + TypeScript + Vite + HTML5 Canvas 2D**, có khách hàng hoạt họa, 3 loại bánh ngọt, 5 cấp thiết bị, tự động hóa nhân viên, thu nhập ngoại tuyến 8 giờ, **Hướng dẫn chơi**, **Tutorial** và **Gợi ý hành động tiếp theo**.

## Tính năng
- **Tiệm bánh Pixel Tương tác:** Lò gạch hoạt họa, quầy trưng bày, hiệu ứng hơi nước, chữ nổi `+coin` và dân làng đi lại.
- **Tiến trình Sâu sắc:** Mở khóa Bánh mì đồng quê, Bánh sừng bò bơ và Bánh tart dâu; mua 5 cấp thiết bị; thuê Thợ làm bánh tập sự và Thu ngân thân thiện.
- **Hỗ trợ & Học chơi:** Hộp thoại **Hướng dẫn chơi**, **Tutorial** 3 bước và cố vấn **Gợi ý hành động tiếp theo**.
