# Cozy Town Tycoon — Ông Trùm Tiệm Bánh Pixel

Một tựa game mô phỏng / idle tiệm bánh pixel 16-bit siêu chill, build bằng **React 18 + TypeScript + Vite + Canvas 2D**. Có khách hàng hoạt họa ghé tiệm, 3 loại bánh ngọt, 5 cấp thiết bị, thuê nhân viên làm thay, thu nhập offline tới 8 tiếng, kèm **How to Play**, **Tutorial** và **Hints** gợi ý bước tiếp theo.

## Tính năng
- **Tiệm bánh Pixel sống động:** Lò gạch đỏ lửa, quầy trưng bày, hiệu ứng hơi nước, chữ `+coin` nhảy nhót và dân làng đi lại tấp nập.
- **Tiến trình nâng cấp cuốn hút:** Mở khóa Bánh mì đồng quê, Bánh sừng bò bơ và Bánh tart dâu; sắm 5 cấp thiết bị xịn hơn; thuê Thợ làm bánh tập sự và Thu ngân thân thiện để tự động hóa tiệm.
- **Dễ làm quen:** Bảng **How to Play**, **Tutorial** 3 bước nhanh gọn và cố vấn **Hints** nhắc bạn nên làm gì tiếp theo.
