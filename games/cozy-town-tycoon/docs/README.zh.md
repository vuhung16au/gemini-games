# 温馨小镇大亨 — 像素风面包店

一款温馨的 16-bit 像素风面包店放置/经营网页游戏，基于 **React 18 + TypeScript + Vite + HTML5 Canvas 2D** 构建，包含动画顾客、3 种糕点、5 级设备升级、员工自动化、8 小时离线收益、**玩法说明**、**教学模式** 与 **下一步行动提示**。

## 核心特性
- **交互式像素面包店：** 动态砖炉、陈列柜台、蒸汽粒子特效、`+coin` 飘字与来往的小镇居民。
- **丰富成长线：** 解锁乡村面包、黄油牛角包与浆果挞；购买 5 级设备升级；雇佣面包学徒与友善收银员。
- **辅助与引导：** 内置 **玩法说明** 弹窗、3 步引导 **教学模式** 以及 **下一步提示** 顾问。
