# Cozy Town Tycoon — Pixel Bakery

A cozy 16-bit pixel-art bakery idle/tycoon web game built with **React 18 + TypeScript + Vite + HTML5 Canvas 2D**, featuring animated customers, 3 pastries, 5 equipment tiers, staff automation, 8-hour offline earnings, **How to Play**, **Tutorial**, and **Next-Action Hints**.

## Features
- **Interactive Pixel Bakery:** Animated brick oven, display counter, steam particles, floating `+coin` popups, and walking townsfolk.
- **Deep Progression:** Unlock Country Bread, Butter Croissant, and Berry Tart; buy 5 equipment tiers; hire Apprentice Bakers and Friendly Cashiers.
- **Assist & Learning:** In-game **How to Play** modal, 3-step guided **Tutorial**, and **Next-Action Hint** advisor.
