# Quickstart — 1024

## Prerequisites
- **Node.js** 18+ and **npm**

## Local Setup & Play

From the repository root (unified web app):

```bash
npm run dev
```

Or standalone inside `games/1024/`:

```bash
cd games/1024
npm install
npm run dev
```

## Automated Tests & Build

```bash
npm test
npm run test:e2e
npx tsc --noEmit
npm run build
```
