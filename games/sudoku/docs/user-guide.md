# User Guide — Sudoku

## Objective
Fill the **9×9 grid** so that every **row**, **column**, and **3×3 box** contains the digits **1 through 9** without repetition.

## Controls

### Desktop (Keyboard & Mouse)
- **Click** any cell to select it.
- **Arrow Keys** move the selection across the grid.
- **1–9** enter a digit (or toggle a pencil note when Notes mode is ON).
- **Backspace / Delete / 0** erase the selected cell.
- **N** — Toggle **Notes** mode.
- **Z** — **Undo** the last move.
- **H** — Use a **Hint** on the selected (or next empty) cell.
- **P** — **Pause / Resume** the timer.

### Mobile / Touch
- Tap any cell on the 9×9 grid, then tap **1–9** on the number pad or use **Undo**, **Erase**, **Notes**, and **Hint**.

## Rules & Settings
- **Mistakes:** You have up to **3 mistakes** per puzzle. Entering an incorrect digit highlights it in red and increments the mistake counter.
- **Auto-Note Cleanup:** Placing a correct digit automatically removes that digit from pencil notes in the same row, column, and 3×3 box.
## Learning & Assist Tools
- **? Help:** Opens the in-game rules, controls, and shortcuts modal.
- **Tutorial:** Launches a 3-step guided practice puzzle (enter a digit, add a pencil note, and complete with Hint).
- **Audio & Persistence:** Use the **🔊 / 🔇** button to mute/unmute sound effects. Your selected difficulty, mute preference, games won, and best times per difficulty are saved automatically in `localStorage`.
