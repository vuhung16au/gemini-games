# 坦克大战 (1985) — Famicom / NES

忠实还原 Namco 1985 年经典街机/红白机游戏 **坦克大战 (Battle City)** 的网页版本，支持 **单人模式** 与 **双人本地合作模式**。

## 核心特性
- **经典 13×13（26×26 子格）战场：** 可破坏半格砖墙、钢铁装甲、森林掩体、水域障碍、打滑冰面与老鹰基地防御。
- **单人 & 双人本地合作：** 可单人游玩（`WASD` / `方向键` + `空格` / `回车`）或双人配合（`1P: WASD + 空格`，`2P: 方向键 + 回车`），并还原 2.5 秒友军误伤定身机制。
- **4 种敌军坦克与 6 种道具：** 普通、快速、强化与 4 血重装坦克；星星（`★` 1–3 级）、头盔、时钟、铁铲、手雷与 1UP 坦克。
- **10 个手工关卡 + 教学与提示：** 支持选关（`1–10`）、过关击毁统计、4 步交互式教学与实时战术提示。
