# Dino Run — Quickstart

Run all commands from `games/dino-run/`:

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run Vitest unit tests
npm test

# Run Playwright E2E browser tests (port 4184)
npm run test:e2e

# Type-check and produce static production build (dist/)
npx tsc --noEmit && npm run build

# Preview production build locally
npm run preview
```
