# Dino Run — User Guide

## Objective
Run as far as possible without colliding with desert cacti/pterodactyls (Classic mode) or math obstacles (404 Math mode). Speed ramps up as your score climbs!

## Controls
- **Jump / Start:** `Space`, `Up Arrow`, `W`, or tap the canvas / **Jump** button
- **Duck / Fast-Fall:** Hold `Down Arrow`, `S`, or **Duck** button
- **Pause:** `P` or `Escape`

## Features & Persistence
- Switch between **Classic** (Day/Night every 700 pts) and **404 Math** anytime.
- Use **Tutorial** for a 3-step guided practice run, **💡 Hint** for live jump/duck timing markers, and **? Help** for quick reference.
- High score, selected theme, and Mute state persist automatically in `localStorage` (`dino_run_v1`).
