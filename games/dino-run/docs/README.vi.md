# Khủng Long Chạy Bộ (Dino Run) — 404 Runner

Trò chơi khủng long T-Rex chạy vô tận lấy cảm hứng từ game 404 ngoại tuyến của Chrome và HSC QuestionBanks 404 Proof Runner (`DinoGame.tsx`).

## Tính năng chính
- **Hai Chế độ Tùy chọn:**
  - **Sa mạc Cổ điển:** Xương rồng pixel, thằn lằn bay vỗ cánh, mây trôi và chu kỳ Ngày/Đêm mỗi 700 điểm.
  - **404 Chứng minh Toán học:** Khủng long đội mũ tốt nghiệp né `∑`, `∫`, `[A]` và chướng ngại vật có cánh `−` / `÷0` trên nền giấy kẻ ô với các công thức toán học bay lơ lửng.
- **Điều khiển Nhạy bén:** `Space`/`Lên`/`W` để nhảy, `Xuống`/`S` để cúi hoặc rơi nhanh trên không, kèm điều khiển chạm/nhấp chuột.
- **Hướng dẫn & Lưu trữ:** **Hướng dẫn chơi** trong game, **Tutorial** 3 bước, dấu nhắc thời điểm **Gợi ý** trực tiếp (`JUMP ↑` / `DUCK ↓`) và lưu `localStorage` (`dino_run_v1`).
