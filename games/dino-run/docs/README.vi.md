# Dino Run — Khủng Long Mất Mạng 404

Game khủng long T-Rex chạy bất tận lấy cảm hứng từ màn hình 404 mất mạng huyền thoại của Chrome và HSC QuestionBanks 404 Proof Runner (`DinoGame.tsx`).

## Tính năng chính
- **2 chế độ đổi gió:**
  - **Sa mạc Cổ điển:** Xương rồng pixel, thằn lằn bay vỗ cánh, mây trôi và chu kỳ Ngày/Đêm đổi màu mỗi 700 điểm.
  - **404 Chứng minh Toán học:** Khủng long đội mũ tốt nghiệp né `∑`, `∫`, `[A]` và chướng ngại vật có cánh `−` / `÷0` trên nền giấy kẻ ô với loạt công thức toán bay lơ lửng.
- **Điều khiển mượt mà:** `Space`/`Lên`/`W` để nhảy, `Xuống`/`S` để cúi đầu hoặc rơi nhanh khi đang trên không, hỗ trợ cả chạm/click chuột.
- **Hỗ trợ & lưu điểm:** **How to Play** ngay trong game, **Tutorial** 3 bước, **Hints** nhắc nhịp nhảy/cúi trực tiếp (`JUMP ↑` / `DUCK ↓`) và lưu `localStorage` (`dino_run_v1`).
