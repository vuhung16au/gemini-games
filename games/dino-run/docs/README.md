# Dino Run — 404 Runner

An endless T-Rex runner inspired by Chrome's offline 404 dinosaur game and the HSC QuestionBanks 404 Proof Runner (`DinoGame.tsx`).

## Key Features
- **Two Selectable Modes:**
  - **Classic Desert:** Pixel cacti, flapping pterodactyls, clouds, and Day/Night cycles every 700 points.
  - **404 Math Proof Runner:** Graduation-cap T-Rex dodging `∑`, `∫`, `[A]`, and winged `−` / `÷0` hazards over graph paper with floating math formulas.
- **Responsive Controls:** `Space`/`Up`/`W` to jump, `Down`/`S` to duck or fast-fall mid-air, plus touch/click controls.
- **Guidance & Persistence:** In-game **How to Play**, 3-step **Tutorial**, live **Hint** timing markers (`JUMP ↑` / `DUCK ↓`), and `localStorage` persistence (`dino_run_v1`).
