# 南越十三张 (Tiến Lên Miền Nam) — 南越经典跑牌游戏

**Tiến Lên Miền Nam** 是一款地道的南越 52 张跑牌游戏，基于 TypeScript、React 18 与 Vite 构建。支持单人挑战智能 AI，或在 **Pass & Play** 模式下与 **2、3 或 4 位玩家** 在同一台设备上本地传机对战。

## 核心特性

- **地道南越规则：** 牌面大小 `3 < 4 < … < A < 2`，同点数比花色 `♠ < ♣ < ♦ < ♥`，支持灵活混色顺子（`>= 3` 张，不含 `2`）以及首轮出牌优先权（`3♠` 或最小手牌）。
- **砍猪 / 炸弹（Chặt Heo）层级：**
  - **3 连对（3 Đôi thông）** 可砍单张 `2` 或更小的 3 连对。
  - **四条（Tứ quý）** 可砍单张 `2`、对 `2`、3 连对或更小的四条。
  - **4 连对（4 Đôi thông）** 可砍以上全部以及更小的 4 连对。
- **天胡（Tới Trắng，发牌即胜）：** 持有 **一条龙（`3→A`）**、**6 对** 或 **四条 `2`** 时自动获胜。
- **2–4 人 × 双模式：** 在 `2P`、`3P`、`4P` 与 `vs AI` / `Pass & Play`（带隐私遮挡幕布）之间无缝切换。
- **双语界面：** 所有操作（`Đánh / Play`、`Bỏ lượt / Pass`、`Xếp bài / Sort`）、规则弹窗、3 步教学与 `💡 Gợi ý / Hint`。
- **程序化音效与本地持久化：** 零外部资源；Web Audio 音效带静音开关，并使用 `tien_len_mien_nam_v1` 进行 `localStorage` 持久化。
