# Quickstart — Tá Lả (Phỏm)

Run these commands inside `games/ta-la-phom/`:

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Run Vitest unit tests
npm test

# Run Playwright E2E browser tests (port 4185)
npm run test:e2e

# Type-check with strict TypeScript
npx tsc --noEmit

# Build static production bundle into dist/
npm run build

# Preview production bundle
npm run preview
```
