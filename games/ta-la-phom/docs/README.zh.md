# 越南吃牌扑克 (Tá Lả / Phỏm) — 越南经典纸牌游戏

一款地道、支持离线游玩的 **Tá Lả (Phỏm)** 网页版实现，基于 TypeScript、React 18 与 Vite 5 构建。

## 核心特性

- **地道 4 轮规则：** 52 张标准扑克，庄家发 10 张、闲家发 9 张，其余进入 **Nọc** 摸牌堆；严格 **Ăn / 吃牌** 校验（每组 Phỏm 最多含 1 张吃牌）；第 4 轮 **Hạ Phỏm / 亮牌** 与 **Gửi bài / 寄牌**；支持即时 **Ù**（和牌）与 **Móm / Cháy** 判定。
- **最优回溯求解器（`solveOptimalMelds`）：** 穷举计算最小散牌点数（`A=1`、`2–10=面值`、`J=11`、`Q=12`、`K=13`），同时覆盖所有吃进的牌。
- **2–4 人 × 双模式：** 支持 `2P`、`3P` 或 `4P` 对战智能 AI（`vs AI`），或与好友本地传机同玩（`Pass & Play`，配有 **隐私遮挡幕布**）。
- **双语界面与引导：** 越南语 + 英语标签、`? 帮助` 弹窗、`💡 提示`（`getPhomHint`）、3 步 `教学模式`（`摸牌/吃牌 -> 出牌 -> 组 Phỏm`）以及程序化 Web Audio 音效与静音开关。
- **零滚动条（`100dvh`）：** 响应式牌桌布局，搭配清晰的 CSS/SVG 扑克牌（`♠ ♣ ♦ ♥`）与安全的 `localStorage` 持久化（`ta_la_phom_v1`）。
