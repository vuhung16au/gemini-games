# User Guide — Tetris

## Objective
Guide falling Tetrominoes onto the **10×20** playfield to complete horizontal rows. Completed rows clear, earn points, and advance the level every **10 lines**.

## Controls

### Keyboard
- **← / →** — Move left / right
- **↑ / X** — Rotate clockwise
- **Z** — Rotate counter-clockwise
- **↓** — Soft drop (`+1` point per row)
- **Space** — Hard drop (`+2` points per row)
- **C / Shift** — Hold active piece (once per drop)
- **H** — Show **Smart Hint** placement outline
- **P** — Pause / Resume

### Touch / Mobile
- Use the on-screen **◀ / ▼ / ▶ / ↻ / Hold / ⤓ Drop** arcade buttons below the board.

## Learning & Features
- **? How to Play:** View controls and scoring anytime inside the game.
- **Tutorial:** Guided 3-step practice covering Rotation, Hard Drop line clear, and Hold.
- **Ghost Toggle:** Show or hide the translucent landing preview at the bottom of the board.
- **Persistence:** High score, best lines, best level, ghost preference, and mute setting save automatically to `localStorage`.
